# CareFlow – Key Business Insights

## 1. Project Overview
CareFlow analyzes hospital workflow event data to understand patient activity patterns and operational processes.

## 2. Key Findings

### Dataset Overview
- Total Events: 6,443 (raw dataset)
- Unique Patient Cases: 1,000
- Number of Activity Types: 6

### Activity Analysis
- Doctor activity recorded 1,240 events.
- Activity frequency analysis helps identify commonly performed hospital activities.

### Patient Journey Analysis
- Patient activity sequences help understand the order of activities in each case.
- Process mining helps visualize transitions between activities.

### Department Analysis
- Department-wise activity analysis helps compare workflow patterns across departments.

## 3. Business Recommendations
- Monitor frequently occurring activities.
- Review patient workflow transitions to identify possible process delays.
- Use department-wise analysis to support operational planning.
- Track workflow performance regularly through dashboards.

## 4. Tools Used
- Python
- Pandas
- SQL
- BigQuery
- Power BI
- PM4Py

## 5. Conclusion
The analysis provides an overview of hospital workflow patterns and supports data-driven operational review.
